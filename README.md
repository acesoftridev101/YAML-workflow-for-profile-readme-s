# YAML-workflow-for-profile-readme-s
This is a YAML workflow for profile readme's that creates two SVG files. The top languages you used on GitHub, which would be called top-langs.svg, and another one named stats.svg. The stats.svg give you your stats on GitHub. You can run the workflow by creating a new repository, adding the yml file with the folder, going in actions, then Update README Stats, finally press run workflow. Or you can let it sit because the workflow always automatically turns on at midnight UTC.
