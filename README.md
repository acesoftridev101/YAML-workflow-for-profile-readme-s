# YAML-workflow-for-profile-readme-s
This is a YAML workflow for profile readme's that creates two SVG files. The top languages you used on GitHub, which would be called top-langs.svg, and another one named stats.svg. The stats.svg give you your stats on GitHub. You can run the workflow by creating a new repository, adding the yml file with the folder, going in actions, then Update README Stats, finally press run workflow. Or you can let it sit because the workflow always automatically turns on at midnight UTC. By the way these files will be inputted in a "profile" folder. It will make it so that it's not displayable on the profile readme. What you do is that you download the two SVG files off your repository and delete the two SVG files off your repository. Next, you upload the two SVG files back up and put them on the MAIN BRANCH. Don't put the two SVG files back in a folder again. Then you're able to use it in your profile readme. Example is on my profile. The two SVG files are also on my acesoftridev101/acesoftridev101 repository.
